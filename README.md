# পাবিপ্রবি চাঁপাইনবাবগঞ্জ জেলা সমিতি (PUST Chapainawabganj Zilla Samity)

পাবনা বিজ্ঞান ও প্রযুক্তি বিশ্ববিদ্যালয়ে (পাবিপ্রবি) অধ্যয়নরত চাঁপাইনবাবগঞ্জ জেলার শিক্ষার্থীদের ডাটাবেজ, মেস ও আবাসন সহায়তা, ভর্তি সেল, জরুরি রক্তদান নেটওয়ার্ক এবং ডিজিটাল স্টুডেন্ট মেম্বারশিপ কার্ড ব্যবস্থাপনার একটি আধুনিক ফুল-স্ট্যাক ওয়েব পোর্টাল।

## 🌟 প্রধান প্রধান ফিচারসমূহ (Key Features)

### ১. 📝 শিক্ষার্থী ও সদস্য নিবন্ধন (Student Registration System)
রেজিস্ট্রেশন ফর্মে অন্তর্ভুক্ত আবশ্যকীয় তথ্য:
- পূর্ণ নাম, পাসপোর্ট সাইজ ছবি আপলোড
- অনুষদ ও বিভাগ, একাডেমিক সেশন (২০১০-১১ থেকে ২০২৪-২৫)
- ইউনিক স্টুডেন্ট আইডি / রোল নম্বর
- জরুরি মোবাইল নম্বর ও ইমেইল ঠিকানা
- নিজ উপজেলা (চাঁপাইনবাবগঞ্জ সদর, শিবগঞ্জ, গোমস্তাপুর, নাচোল, ভোলাহাট)
- পেশা, পাবনায় বর্তমান মেস/হলের ঠিকানা
- রক্তের গ্রুপ এবং স্বেচ্ছায় রক্তদানে ইচ্ছুক হওয়ার অপশন
- নিরাপদ পাসওয়ার্ড সংরক্ষণ

### ২. ✅ নিবন্ধন নিশ্চিতকরণ সেকশন (Registration Confirmation)
- ফরম সাবমিট করার সাথে সাথেই শিক্ষার্থী একটি আকর্ষণীয় নিশ্চিতকরণ স্লিপ পাবে।
- স্ট্যাটাস ব্যাজ: `⏳ Pending Admin Verification`
- প্রিন্ট বা সেভ স্লিপ বাটন (`window.print()`)

### ৩. 🩸 জরুরি রক্তদান নেটওয়ার্ক (Emergency Blood Directory)
- পাবনা ও চাঁপাইনবাবগঞ্জের যেকোনো রোগীর জরুরি প্রয়োজনে রক্তদাতা খোঁজার বিশেষ ব্যবস্থা।
- রক্তের গ্রুপ অনুযায়ী তাৎক্ষণিক ফিল্টারিং।
- সরাসরি **কল (Call)** এবং **হোয়াটসঅ্যাপ (WhatsApp)** বাটন।

### ৪. 🤝 শিক্ষার্থী সহায়তা ও কল্যাণ সেল (Student Support Services)
- **ভর্তি সহায়তা সেল (Admission Helper):** নতুন ভর্তি পরীক্ষার্থীদের বাস কাউন্টার থেকে রিসিভ ও দিকনির্দেশনা।
- **মেস ও আবাসন সহায়তা (Mess & Accommodation):** পাবনায় নিরাপদ ছাত্র ও ছাত্রী মেস নির্বাচনে সহায়তা।
- **ক্যারিয়ার ও মেন্টরিং:** সিনিয়র গ্র্যাজুয়েটদের ক্যারিয়ার গাইডলাইন।
- **উপজেলা সমন্বয়ক হেল্পডেস্ক:** ৫টি উপজেলার জন্য পৃথক দায়িত্বশীলদের যোগাযোগের ব্যবস্থা।

### ৫. 🔍 শিক্ষার্থী ডিরেক্টরি (Student Directory with DataTables)
- লাইভ সার্চ ও উপজেলা ফিল্টার পিলস।
- এক ক্লিকেই শিক্ষার্থীর বিস্তারিত তথ্য ও সরাসরি যোগাযোগের পপ-আপ প্রিভিউ।

### ৬. 🪪 শিক্ষার্থী ইউজার প্যানেল ও ডিজিটাল আইডি কার্ড (User Panel)
- শিক্ষার্থীদের জন্য আকর্ষণীয় **ডিজিタル স্টুডেন্ট আইডি কার্ড**।
- আইডি কার্ডে রয়েছে পাবিপ্রবি ও জেলা সমিতির সিল, ছবি, আইডি, বিভাগ, সেশন, রক্তের গ্রুপ, নিজ উপজেলা এবং ইউনিক কার্ড নম্বর।
- যেকোনো সময় এক ক্লিকেই প্রিন্ট বা পিডিএফ সংরক্ষণের সুবিধা।

### ৭. 🛡️ কেন্দ্রীয় অ্যাডমিন প্যানেল ও ভেরিফিকেশন (Admin Verification Panel)
- **One-Click ভেরিফিকেশন:** নতুন কোনো শিক্ষার্থী রেজিস্ট্রেশন করলে এক ক্লিকে সক্রিয় (Active) অনুমোদন।
- যেকোনো শিক্ষার্থীর তথ্য সংশোধন, নিরাপদ পাসওয়ার্ড রিসেট বা রেকর্ড ডিলিট।
- নোটিশ প্রকাশনা ও ডাউনলোড ফাইল ব্যবস্থাপনার স্বয়ংক্রিয় ব্যবস্থা।

### ৮. 📊 রেজিস্ট্রেশন ডাটা এক্সেল/CSV ও JSON ডাউনলোড (Admin Data Export)
- **এক্সেল / CSV ডাউনলোড:** অ্যাডমিন প্যানেল থেকে এক ক্লিকেই সকল শিক্ষার্থীর নাম, রোল, বিভাগ, সেশন, মোবাইল, ইমেইল, রক্তের গ্রুপ, উপজেলা ও ঠিকানাসহ পূর্ণাঙ্গ তালিকা Microsoft Excel ফরম্যাটে (UTF-8 BOM সহ) ডাউনলোড।
- **JSON ব্যাকআপ:** পূর্ণাঙ্গ ডাটাবেজ ব্যাকআপ নেওয়ার জন্য স্ট্যান্ডার্ড JSON এক্সপোর্ট সুবিধা।

## 🚀 লোকাল সার্ভার চালনা (How to Run Locally)

1. প্রজেক্ট ফোল্ডারে টার্মিনাল খুলুন
2. ডিপেন্ডেন্সি ইন্সটল:
   ```bash
   npm install
   ```
3. লোকাল সার্ভার চালু করুন:
   ```bash
   npm start
   ```
4. স্ট্যাটিক বিল্ড জেনারেট করুন (GitHub Pages-এর জন্য):
   ```bash
   npm run build
   ```
